# Airport Baggage Handling Simulator

## Project Overview

The Airport Baggage Handling Simulator is a web-based educational project developed using HTML, CSS, and JavaScript. It provides a visual simulation of airport baggage handling operations and demonstrates how tasks can be processed and managed efficiently.

## Objectives

* Simulate airport baggage handling operations through an interactive interface.
* Visualize baggage processing and task flow.
* Demonstrate relevant Operating Systems concepts through simulation.
* Provide a simple and user-friendly interface for learning and experimentation.

## Technologies Used

* **HTML** — Webpage structure
* **CSS** — Styling and visual layout
* **JavaScript** — Simulation logic and interactivity

## Project Files

* `index.html` — Main webpage
* `script.js` — Simulation logic
* `style.css` — Styling and layout

## How to Run

1. Download or clone the project repository.
2. Open the project folder.
3. Double-click `index.html` to launch the simulator in a web browser.

## Purpose

This project was developed as an academic mini-project to explore the practical application of Operating Systems concepts through an interactive airport baggage handling simulation.
